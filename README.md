# City Cleanliness Assessment System

## Project Overview
The City Cleanliness Assessment System is a smart web application designed to analyze and monitor the cleanliness levels of different areas in a city using image-based analysis.

The system uses Machine Learning and Computer Vision techniques to classify images of city locations into different cleanliness categories. This helps municipal authorities identify unclean areas and take necessary action to improve urban sanitation.

The project demonstrates how Artificial Intelligence and web technologies can be used to support smart city initiatives and environmental sustainability.

## Features
- Upload images of city locations
- Cleanliness detection using image classification
- Computer vision analysis of waste and cleanliness
- Classification of areas based on cleanliness levels
- Interactive user interface built with React
- Helps identify areas that require cleaning

## How It Works
1. The user uploads an image of a city area.
2. The image is sent to the backend server.
3. The ML model processes the image using computer vision.
4. The system classifies the cleanliness level.
5. The result is displayed on the frontend.

## Installation

### 1. Clone the repository
git clone https://github.com/your-username/city-cleanliness-assessment-system.git

### 2. Navigate to the project folder
cd city-cleanliness-assessment-system

### 3. Install frontend dependencies
cd frontend
npm install
npm start

### 4. Install backend dependencies
cd backend
pip install -r requirements.txt

### 5. Run the backend server
python app.py

### 6. Open in browser
http://localhost:3000
